How We Build

The rules that keep this real
One section at a time, usable on day one.No half-built everything. A section ships when Nick can use it that shift.
The repo is the OS.Everything — playbooks, brain, cockpit code — lives in git. Clone it anywhere and the whole OS comes with it.
Same language everywhere.One-sentence logging, cockpit meters, gold-on-asphalt. Learning one section means knowing them all.
Data stays Nick's.Local server binds 127.0.0.1 only; Airtable is his base; nothing auto-sends, ever.
Sales pays for everything.Section 01 gets priority on polish — it's the engine that funds the rest of the board.
Say the word, get the section."Build the Brain tab" is a complete instruction. Claude designs it with Nick, then ships it.
