# Social Scripts: Facebook Marketplace Listing Template

Rules from `../../playbooks/lead-engines/social-video.md` §2: 3–5 live
listings, refreshed every 7 days, 10+ photos (flaws included), honest always.
Confirm store policy on personal listings before ramping.

---

## Title format

`{{year}} {{make}} {{model}} {{trim}} — {{mileage}} mi — {{hook}}`

Hook examples: "One Owner", "New Tires + Brakes", "Heated Everything",
"Tow Package", "Clean CarFax".

## Description template


## Photo checklist (10+ shots, natural light, clean background)

1. Front 3/4 (the money shot — this is the thumbnail)
2. Rear 3/4
3. Straight-on front and rear
4. Driver's seat view — wheel, dash, screen ON
5. Odometer (actual mileage showing)
6. Back seat + cargo area (seats folded for SUVs/trucks: show the space)
7. Wheels/tires close-up (tread visible if it's a selling point)
8. Engine bay (clean)
9. The flaw photo — whatever the honest note mentions
10. Window sticker or features screen, if strong
11. Optional but powerful: you standing with the vehicle

## Refresh routine (weekly, via `/daily` Saturday slot)

- Renew every listing at day 7.
- Flat listing (few views, no messages) → new thumbnail photo + new hook line,
  or swap the unit out entirely.
- Sold? Delete same day and backfill from this week's inventory — pick units
  with photo appeal and a value story, not just aged stock.
- Log listings live + messages received via `/log`.
